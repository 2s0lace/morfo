## 📖 O aplikacji

**Morfo** to mobilna aplikacja stworzona z myślą o studentach kierunku lekarsko-dentystycznego, ułatwiająca naukę anatomii opisowej i morfologii zębów stałych. Zamiast płaskich rycin z podręcznika, pozwala badać zęby jako pełnowymiarowe, rzeczywiste skany 3D, porównywać je bezpośrednio ze sobą oraz trenować rozpoznawanie przed kolokwiami i egzaminami.

---

## ✨ Najważniejsze funkcje

- 🔍 **Porównywanie zębów obok siebie w 3D**  
  Wybierz dowolną liczbę zębów z diagramu łuku zębowego (np. pierwszy vs. drugi przedtrzonowiec, siekacz przyśrodkowy vs. boczny) i obracaj je synchronicznie lub niezależnie.
- 📐 **Rzeczywiste proporcje podręcznikowe (Wheeler)**  
  Wszystkie zęby są wyskalowane zgodnie ze średnimi wymiarami anatomicznymi (korona + korzeń) według tablic *Wheeler’s Dental Anatomy*.
- 🔄 **Powierzchnie anatomiczne jednym kliknięciem**  
  Błyskawiczne ustawianie zębów w rzutach anatomicznych:
  - Powierzchnia przedsionkowa (*wargowa / policzkowa*)
  - Powierzchnia językowa / podniebienna
  - Powierzchnia mezjalna
  - Powierzchnia dystalna
  - Powierzchnia żująca / brzeg sieczny
- 🧠 **Quiz rozpoznawania zębów (standard FDI)**  
  Trening identyfikacji zęba w losowej orientacji przestrzennej bez podpowiedzi wielokrotnego wyboru – dokładnie tak, jak na egzaminie praktycznym.
- 🗂️ **Inteligentne fiszki (*Spaced Repetition*)**  
  Tryb fiszek z powtórkami przestrzennymi: zęby, z którymi miewasz problem, pojawiają się częściej, a te opanowane trafiają do rzadszych powtórek.
- 🦷 **Wariant z guzkiem Carabellego**  
  Możliwość natychmiastowego przełączenia na okaz górnego pierwszego trzonowca z wyraźnym guzkiem Carabellego.
- 🌐 **Dwujęzyczność (Polski / Angielski)**  
  Pełne nazewnictwo i opis cech morfologicznych w języku polskim lub angielskim (przełącznik w ustawieniach).

## 📲 Jak zainstalować aplikację?

1. Kliknij zielony przycisk [**Pobierz na Androida (APK)**](https://github.com/2s0lace/morfo/releases/latest/download/Morfo.apk) powyżej (lub wybierz plik `Morfo.apk` ze strony [Releases](https://github.com/2s0lace/morfo/releases/latest)).
2. Po zakończeniu pobierania otwórz plik `Morfo.apk` na swoim telefonie lub tablecie.
3. Jeśli system wyświetli ostrzeżenie o instalacji z nieznanych źródeł, wybierz opcję **„Ustawienia”** i włącz **„Zezwalaj z tego źródła”** (jest to standardowa procedura systemu Android dla aplikacji instalowanych bezpośrednio poza sklepem Google Play).
4. Kliknij **Zainstaluj** i uruchom aplikację.

## 🎮 Sterowanie w widoku 3D

| Gest | Działanie |
|---|---|
| **Jeden palec** | Obrót zęba wokół osi anatomicznych |
| **Dwa palce (przeciągnięcie)** | Przesuwanie widoku (panoramowanie) |
| **Dwa palce (uszczypnięcie)** | Przybliżanie / oddalanie (zoom) |
| **Skręt dwoma palcami** | Obrót kamery wokół osi patrzenia |
| **Przytrzymanie i przeciągnięcie** | Swobodne przemieszczenie wybranego zęba |
| **Pojedyncze stuknięcie** | Zaznaczenie / odznaczenie zęba |
| **Podwójne stuknięcie** | Automatyczne wyśrodkowanie i dopasowanie widoku |
